# 철도모형 레이아웃 시뮬레이터 — 내려받기

실제 제품 규격 레일(KATO 유니트랙 HO·N, TOMIX 파인트랙 N)로 판 위에 레이아웃을 짜고, 3D 로 열차를 달리게 하는 Windows 게임의 설치 파일을 올려 두는 곳입니다. 소스 코드는 여기 없습니다.

- 3D 화면에서 바로 레일·승강장·역사·건물 놓기, 평면도 편집기
- 이벤트(감지점·시각·키 → 분기기·정지·기적 …)와 JS 스크립트
- 카메라 저장, 걷기 시점, 운전실 HUD, 관람 모드, 스크린샷

## 설치

1. [최신 릴리스](https://github.com/ykyyyky55-cmd/rail-model-sim-releases/releases/latest)에서 `RailModelSim-<버전>-setup.exe`를 내려받아 실행합니다.
2. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다. 코드 서명이 없는 프로그램이라 뜨는 창입니다.
3. 설치 위치를 고르고 설치합니다. 관리자 권한은 필요 없습니다.

- Windows 10/11 64비트
- 설치한 게임은 켤 때 새 버전을 확인하고, 있으면 받을지 묻습니다. 직접 확인하려면 Alt → 도움말 → 업데이트 확인.
- 설치 없이 쓰려면 `RailModelSim-<버전>-portable.exe`를 받아 바로 실행합니다(자동 업데이트 없음).
- 「HO 철도모형 디오라마」와는 따로 설치되고 저장도 따로입니다.

## 저장

만든 레이아웃은 `%APPDATA%\RailModelSim`에 저장되고, 업데이트하거나 제거해도 남습니다.
다른 PC로 옮기려면 내 레이아웃 카드의 ⬇(파일로 내보내기)로 파일을 만들고, 그 PC에서 📂 파일 열기를 합니다.

## 사용한 외부 자료

- **ITX-새마을 3D 모델**: 「ITX-새마을 (Korail210000)」 OpenBVE 애드온 — 해산강제작소, Bong Gu, 고독한 미식가, 금촌역, 진흙쿠키, SRT 수서고속철도, 최연수, 세계인 에스티, 무기무기, 선혈, 철도인생, Loco 7374, Mtattrain 외.
  이용 조건(비상업적 사용, 출처를 밝힌 2차 수정·배포 허용, 사운드 수정 금지)에 따라 게임 형식으로 변환해 넣었고, 사운드는 쓰지 않았습니다. 이 게임은 무료이며 상업적으로 쓰지 않습니다.
- **7300호대 디젤기관차·무궁화호 객차·발전차 3D 모델**: 「GT26CW-2형 기관차(7315호) + 나뭇결 무궁화호」 OpenBVE 애드온 — 해산강제작소 배포.
  기관차: 모델링·외부 텍스처 B701, 기관실 텍스처 5879·B701, 그림자 고독한 미식가. 객차: 2+3객차 통로 철도인생(i11lo3), 발판 SRT·김샘·haimlog, 행선판 박태식, 발전차 텍스처 izoa0486, 그 밖의 텍스처 고독한 미식가(datsys).
- **7300·7500호대 소리(엔진·기적·제동 공기음)**: 같은 애드온의 수록 음원 — 구동음 고독한 미식가, Taiga8500, 진위역, xoqja0258.
  이 애드온은 출처를 밝히면 자유롭게 수정·배포할 수 있어, 모델은 길이를 실물 치수에 맞춰 게임 형식으로 변환하고 소리는 잘라 압축해 넣었습니다.
- **나무·풀·꽃·바위**: [Poly Haven](https://polyhaven.com) 의 CC0 3D 모델을 그림으로 구워 넣었습니다.
- **사진 질감**: [ambientCG](https://ambientcg.com) 의 CC0 질감.
- **사람 3D 모델**: [Adobe Mixamo](https://www.mixamo.com) 캐릭터 「Remy」·Ch22·Ch33·Ch41 — Mixamo 이용 조건(게임 안에 넣어 쓰는 것 허용, 원본 파일 재배포 금지)에 따라 자세를 잡고 줄여 게임 형식으로 변환한 것만 넣었습니다. 원본 파일은 들어 있지 않습니다.
- **다락방 레이아웃 예제**: SCARM 레이아웃 도면 「Dachboden-V15_3a」(제공받은 도면의 인쇄본)에서 선로 배치·높이·터널·풍경 배치를 읽어 옮겼습니다. SCARM 프로그램의 부품 라이브러리 파일은 쓰지 않았습니다.
- 레일 부품 치수는 KATO·TOMIX 의 공개 제품 정보(길이·반지름·각도)만 썼고, 제품 그림·데이터는 쓰지 않았습니다. 「鉄道模型シミュレーター」(아이매직)의 데이터는 쓰지 않았습니다.
